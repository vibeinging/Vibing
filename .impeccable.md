# Vibing Design Context

## Target Audience
Full-stack engineers using Vibing as their daily local terminal emulator on macOS.

## Use Cases
- Local terminal sessions with multi-tab and split-pane workflows
- Quick command execution, file navigation, and development tasks
- Customizing terminal appearance with multiple themes

## Brand Personality
Warm, friendly, and approachable — like a well-crafted tool that feels personal.
Modern simplicity with careful attention to comfort and usability.
Not cold or clinical; not flashy or distracting. A quiet confidence.

## Design Direction
- **Tone**: Warm minimalism — clean lines softened by warm tones and gentle transitions
- **Differentiation**: The terminal that feels like home — inviting where others are intimidating
